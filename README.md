# 🌍 TripWise – Explore Smart, Travel Wise

TripWise is a modern and responsive travel website that helps users discover amazing destinations, explore curated tour packages, and plan unforgettable adventures — all in one place. Designed for travel agencies, bloggers, or anyone passionate about exploring the world.

---

## ✨ Features

- 🧭 Beautiful landing page with inspiring travel quotes and banner
- 🏖️ Popular destinations showcased with descriptions (beaches, cities, etc.)
- ✅ Highlights of services: Trusted Guides, Friendly Prices, Reliable Tours
- 📱 Fully responsive layout (mobile + desktop)
- 📸 Visual appeal with high-quality imagery and smooth design
- 🔗 Easy to customize for agencies or personal use

---

## 🛠️ Built With

- HTML5  
- CSS3  
- JavaScript (optional/for interactivity)
